Setup (only needed once)

This page saves poems straight into your GitHub repo. Edit the two lines at the top of the script below in this file (owner and repo name) to match your repo. Then create a token at github.com/settings/tokens — "Fine-grained token", give it access to only this one repository, and under Permissions set "Contents" to Read and write. Paste that token above. Keep this page's link and your token private — anyone who has both could post poems.
